# AdriPOS 💜📱

**Tu negocio, en tus manos.**  
AdriPOS es una aplicación móvil diseñada para mujeres emprendedoras que quieren llevar el control de sus ventas, productos y clientes desde el celular, sin depender de computadoras, escáneres o internet constante.

---

## ✨ ¿Por qué AdriPOS?

AdriPOS nació del amor por una mujer emprendedora —mi esposa Adriana— y del deseo de empoderar a muchas más. Ella, como tantas mujeres, vende, organiza, aparta y cobra… todo desde su celular. Esta app fue creada para que pueda hacerlo de forma profesional, fácil y segura.

> “Mientras no ruedo, construyo. Mientras no vendo, programo. Mientras no llega el momento… lo creo.”

---

## 🧠 ¿Qué hace AdriPOS?

- 📦 **Alta de productos** con foto, código, precio y categoría
- 🛒 **Ventas con múltiples artículos y formas de pago** (efectivo, transferencia, crédito)
- 💳 **Créditos y cuentas por cobrar** con abonos parciales
- 📋 **Apartados y encargos** con seguimiento
- 👤 **Gestión de clientes** con búsqueda y edición
- 📶 **Funciona sin internet** (base local SQLite)
- ☁️ **Listo para sincronizar con la nube** (SQL Server) como respaldo o expansión

---

## 🧱 Arquitectura técnica

- **Plataforma**: Android (Xamarin)
- **Base local**: SQLite con control de IDs por rango
- **Sincronización**: planificada con SQL Server (modo respaldo y escalamiento)
- **Diseño modular**: cada entidad (ventas, clientes, productos) es independiente y sincronizable
- **Escalable**: pensado para múltiples clientas, licencias y acceso web/escritorio
